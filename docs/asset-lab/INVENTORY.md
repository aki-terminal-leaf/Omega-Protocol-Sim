# TOP P1–P6：逐階段物件、動作、材質與特效需求

整理日期：2026-10-28。這是既有來源的盤點文件，不是 Unity 開發續跑或完成驗收聲明。未啟動 Unity、桌面、原生播放器、建置或背景開發作業。

## 閱讀方式

- 全表共 96 個演出單元，包含重複輪次與 6 個獨立的進場／結尾過場單元；不是 96 套互不相同的素材。
- 列出的內容是需要具備的素材與生命週期，不表示每一項均已提取、完整解析或正確播放。
- 既有參考影片與 FFLogs 並非同一場。影片秒數只用於尋找外觀，不是同場精確觸發時間；Action ID 也不保證每列所有物件共用一份特效。
- 戰鬥還原以 Boss／機關為主。無玩家呈現仍要保留隱形目標位置、朝向與附著掛點。
- 玩家一般技能、職業 LB 與玩家鏡頭演出另列補充，不因本盤點自動加入無玩家版本。進 P6 與擊殺後強制過場也只列為獨立附錄需求，不變更先前排除過場的開發範圍。
- 原表的「現況／缺口」是 2026-10-27 的有界檢查，後來有補提取與接入，因此本文件不沿用它作為目前缺檔判斷。

## 一、所有階段的共用資源契約

### 角色與機關

每個 body／variant 要有模型（MDL）、部件設定（IMC）、材質（MTRL）、貼圖（TEX）、骨架（SKLB）、附著點（EID）及動作（PAP）。需保留正常身體、武器、左／右部件的顯隱與掛點偏移。

- P1 蟲型：m0110b0001。
- P2 M／F：m0513b0001、m0514b0001。
- P3／P4 Final Omega：m0515b0001；監視器／左右發光部件另有狀態。
- P5 金色 M／F：m0513b0002、m0514b0002，不是 P2 單純加黃色。
- 外圈手臂：m0524，保留左右型號及實際 body。
- Rocket Punch：已知 b0005／b0006 配色變體，完整模型族鍵依原 manifest。
- Sigma 後部機關：m0525b0001，與 Optical 不同。
- Optical：場景物件，由 SGB／MDL／材質動畫與獨立攻擊效果組成，不應當作只有一個 NPC mesh。
- P6 Alpha Omega：m0771b0001；不是 Alpha 陸行鳥。
- 可攻擊隕石／彗星：需要獨立 actor／模型／受擊與破碎生命週期；不以地面圓圈代替。確切型號由來源 manifest／BNpc 關聯判定，不在此猜造。

### 動作與播放時序

每招拆成：出現 → 起手／讀條 → 持續／準備 → 發射／動作 → 命中／結算 → 收招／餘光 → 取消或退場。Action／ActionTimeline、TMB、PAP 與場景 cue 必須串在同一物件的正確時間軸，不可只播 End 或只放命中特效。

### 塔材質包

需求拆層：地面底環、立體核心、光柱／光絲、表面流動／旋轉、充能脈衝、成功結算、失敗效果（若做失敗分支）、餘光與消散。顏色、容量圖樣與啟用狀態依該塔原始來源，而不是臆造通用換色。

需保留原始貼圖、遮罩、混合模式、UV 捲動／扭曲、發光與透明度曲線、尺寸／旋轉、生成和停止時間。塔視覺與踩塔判定為不同資料。

### 連線材質包

需求拆層：線身流紋、邊緣與遮罩、兩端附著光效、準備／啟動／距離狀態（依原資源）、交接、斷線與命中。兩端跟隨 actor／骨骼；線長與紋理流動分開，不能只是兩點間的純色線。

### 其他效果

- 地面預兆：圓、環、扇形、直線、方向箭頭；只顯示原版真的有的預兆。
- 攻擊：炮口蓄光、束體、飛行物、火焰、冰晶、爆光、衝擊環、煙塵、碎片、尾跡。
- 頭標／狀態：圖示、世界頭標、身體附著視效與倒數分開；原版狀態不等於玩家插件 automarker。
- 場景：LVB／LGB／SGB、背景模型、地板、邊界、照明／ENVB、場景材質動畫、切換 cue。
- 音訊：SCD、loop、起止、衰減與 BGM 切換。已解碼或有訊號，不等於已聽覺比對原版。
