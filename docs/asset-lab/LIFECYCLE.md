# 特效生命週期：已驗的子集與未解條件

這是 Godot 4.7.2 無視窗數值檢查，**不是 96 項演出或原版視覺驗收**。

- 來源圖的自然結束界限，只用於跳過已無輸出的有限圖；不表示來源 host 已完成。
- 明確證據指定 `release` 時停止生成，保留既有粒子／延遲尾跡；`kill` 才立即終止。
- 畫面狀態回收不冒充來源停止事件；倒放會以原始時刻與相同 seed 重建。
- 沒有證據的 tether 結束、舊的 6000ms 包絡、檢視器循環長度、預算上限，都不是 host-stop 證據。
- 外部觸發、狀態指令、無限生命、未支援的發射器／粒子／效應或音效尾段，回傳 unknown，不能偷偷套固定壽命。

## 已完成的數值檢查

17 個邊界向量及 300 個由獨立 Python 枚舉實際出生事件求得的生命週期案例通過。控制器已檢查自然尾跡、回收、release、kill、倒放重建。

162 份來源圖中，83 份屬於目前可判定的播放子集，且界限後的取樣無粒子／鏡頭效應殘留；其餘 79 份保留 unknown。這個數字不是完整演出的完成率。

跨模型審查（GPT Luna 提案、Claude Sonnet 5.5 反例、主代理實作）找出一個子發射器出生時間上界被誤作最早出生時間的錯誤：舊界限是 0，但第 57 frame 仍有存活粒子。失敗先實跑保留，再修正為保守的 60-frame 界限；沒有以舊測試通過抵銷反例。

## 重跑

準備既有私人來源快取，不把原始遊戲媒體提交 Git：

```sh
python3 tools/asset_lab/run_lifetime.py --godot GODOT_4_7_2 --data PRIVATE_SOURCE_CACHE --out NEW_EVIDENCE
```

每次要求新輸出目錄，保存獨立向量、完整 runtime log 與 JSON；腳本錯誤即使 Godot 回傳 0 也拒絕通過。原版 shader、來源 host/binder 停止語義、音效尾段與原生／視覺驗收仍須分別處理。
