## 素材與動作的對應

動作 ID 會跨模型家族重用；索引依原紀錄施法者形態／明確核對的四種武器 TMB 綁定，不能只以數字匹配。模型顏色、材質與原始骨架一起載入；不把 P2 模型染金當作 P5。

連線使用原始寬度、色彩與材質曲線的 type-6 子集；兩端為可移動展示掛點，不是原紀錄玩家路徑。Spline、原版 billboard、距離狀態及完整 host 停止語義仍未重現。

塔分別使用 P1 Tower2、Sigma Tower3 原始資源；未把容量／紅藍塔當成任意換色。
