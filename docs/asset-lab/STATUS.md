# Godot 視覺實驗室：開發階段狀態

更新：2026-10-29。**這是來源／工具的開發版，不是 96 項完成版、可下載新包或已部署的新展示。** 僅視覺；音效、音樂、混音與聽覺驗收均排除。現有正式站與 releases 不變。

## 已有可檢視內容

- 96 項需求目錄與原始樣本對照；可獨立檢視模型、骨架動作與支援的特效子集，支援播放／暫停／時間滑桿。目錄覆蓋不等於完成演出。
- 分項複合播放的來源選擇與拒絕診斷；沒有原始過場或轉場證據時不以替代動畫假裝完成。
- 起手特效來源閉包修正：補足原始相依資源，拒絕空選擇／錯誤映射／缺失繼承資產／竄改；採新快取輸出，不改既有快取。
- 場景顯隱／階段快取修正：關閉不再殘留模型，重開及倒放恢復正確場景，快取不再掩蓋失敗診斷；[場景生命週期驗收](SCENE_LIFECYCLE.md)。
- UV 曲線修正：保守單鍵／唯一逆解、精確零係數的端點因式分解，解決兩個實際材質在倒放時保留前一時間點值的問題。

原始媒體與戰鬥紀錄不在 Git。公開 source 不帶素材，執行實驗室需要自己的相符私人來源快取；[執行方法](README.md)。目前沒有新的截圖／影片，README 的舊展示不能視為本實驗室的實測畫面。

## 已驗證與未驗證分開

已接受來源基線 `1398183`；[精簡機器可讀摘要](source-acceptance-summary.json)。Windows Godot 4.7.2 headless 實跑：21 公開合成、42 單鍵／材質、207 spline、21 精確切線／歧義、22 原始材質前進／倒放檢查通過；原始雙精度 UV 在 0／9／45／117／171 幀共 52,230 個分量抽樣，0 個不支援值。這不是 52,230 個特效，也不是全曲線、原生語義或 raster 認證。

在修正前的端點反例、舊 fixture 精度不足、錯誤測試 oracle、沙箱拒絕與審查逾時均保留於 [UV 驗收紀錄](VALIDATION.md)／[唯一逆解紀錄](UNIQUE_SPLINE.md)。後續 PASS 只覆蓋其明列範圍，不改寫歷史失敗。

## 下一階段與剩餘依賴

1. **本階段已補齊** AVFX 編譯遺失的武器／binder 原始區塊：完整位元組、順序、重複欄位與子型標籤保存；5 個原始武器特效／8 個掛點的往返與實際編譯輸出通過，8 個新增＋9 個既有公開測試通過，獨立靜態審查無必修項。[來源保存驗收](BINDER_SOURCE.md)。這是來源依賴修正，不新增渲染公式。
2. CoUF 更新、掛點縮放／旋轉等原生語義仍缺依據；[來源調查](BINDERS.md)。欄位名或上游解析器的預設值不能證明執行規則。
3. 靜態場景顯隱／切換已補齊：12 項父層＋86 項公開檢查通過，六階段原始場景 14,813 項數值檢查通過；獨立 runtime 審查無必修項。這不是原生 SGB／塔狀態或畫面保真通過。
4. host／玩家 pose 與生命週期、原生持續場景狀態、原始 shader／遮罩、頭標與 LB 視覺、六段過場及實際畫面／匯出版驗收繼續 OPEN。
