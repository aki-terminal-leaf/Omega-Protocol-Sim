# 分項複合來源播放

**All-96 演出驗收仍 OPEN；未發布。**

介面的「分項複合演出」由 `asset_lab_unit.gd` 接入原始紀錄控制器，不再只顯示單一模型或單個特效樣本。「原始資源檢視」保留獨立排查用途。

## 時間與來源

`compile_performances.py` 對 96 項盤點建立來源選取；目前 89 項有原始施法／事件選取，六個過場和 P1 離場轉場沒有已證實的原始演出指令，直接回報 unavailable。這不是 89 項演出完成。

- 邊界為原始戰鬥紀錄事件／phase marker／紀錄結尾，附原始 event index，不使用異場影片秒數套偏移。
- 相同招式的重複輪次選取各自的原始 cue key，不複製第一輪排程。
- 複合控制器僅啟用該項選中的 cue，換項／倒放從原始時刻重建。
- review window 含檢視用前後留白，**不是**來源 host kill/release。來源停止條件未知時，不以固定六秒或換項洗成已驗證停止。
- body／tether 是時間上的 context，與動作所有權分開記錄。先前連線缺少解除事件時，列為 unknown；不把沒選來畫的連線當成已解除。
- `source_sampling_supported=false` 表示來源欄位／依賴仍有未支援項；不是已取得完整保真演出的成功回執。

## 版本與掛點

選取檔鎖定六份來源 JSON、catalogue、原始附件資料及 compiler fingerprint。來源或掛點不符即拒絕設定；設定／換項失敗不顯示上一項演出，報告亦不沿用混合來源狀態。

Godot JSON 數字是浮點值；動作查表、實例鍵與動作白名單在 API 邊界正規化為整數。原始 actor ID 如 `22:1` 是字串，不轉成整數。

原始玩家參考骨架／EID 見 [ATTACHMENTS](ATTACHMENTS.md)。這不是錄製玩家的實際種族／動作；人物不繪製。缺失的原始材質、precast 特效、場景物件狀態、音效、頭標、LB、連線停止與過場仍須逐項完成。

## 非桌面驗證

`test_units.gd` 使用實際 scene/UI 檢查路由、模式切換、來源 cue 隔離及倒放；正向 FX 檢查必須取得非空來源幾何，零 active/draw 不算正向覆蓋。`verify_units.py` 另核對原始 cue／事件／prepare 依據和重複輪次獨立性。

這些是 headless 數值／來源檢查，不是 raster 畫面、匯出 Windows 執行或完整演出驗收。舊 inspector 的 native 截圖只適用於舊 frozen build。本日 18:00 後未啟動 AnAn GUI／原生播放／擷取。


## 綁定欄位與播放容量

綁定的 `BPT/BPTP/CoUF/GenD/bRng` 必須是來源中存在的有限整數；缺少欄位不再默認為可播放值。位置偏移的未知欄位清單亦須具有正確格式。`ACT/ACTR` 是軸連結列舉，合法的非零值不應視為未支援。`CoUF=0` 等尚無原生語意證明的值仍拒絕；靜止紀錄不是 native 等價證明。

`z3oa_b0_g14t0c.avfx` 的來源圖在第 45 幀有 2,516 個存活粒子，第 117 幀需要 63,563 次圖計算，超過舊預覽容量。素材實驗室因此使用有界的 4,096 粒子／128,000 計算容量；普通預覽仍為 2,048／16,000，深度與循環上限不變。這是完整求值所需的容量修正，不是裁掉粒子或解除預算，亦不是原始材質、綁定、polyline 或完整演出驗收。

施法準備 AVFX 的來源接線及預設關閉界線見 [PRECAST](PRECAST.md)；仍未完成 native 起停／跟隨／玩家 LB 驗收。
