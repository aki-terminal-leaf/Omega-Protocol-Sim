# v0.3.34 — original weapon-animation milestone

This stage starts from accepted Web32, not the failed Web33 candidate. It adds source-model weapon poses, physical female anatomy correction, original static Optical geometry, and lifecycle cleanup. It retains the accepted practice attack presentation and combat rules.

## Released behavior

- Known M/F weapon action bindings only: 31525, 31526, 31530, 31533. Original sampled model-space PAP poses are synchronized to the simulation clock. Male windups are exercised before impact. The female zero-lead resolution fallback is **not** certification of a visible full female windup/attack sequence.
- Pause freezes sampled state; same-seed R releases ownership. No particle-mask adjustment is presented as a fidelity fix.
- Unverified source AVFX is disabled in release templates. Source/editor runs can explicitly use `--experimental-source-effects`; this requires the editor feature and is not a product setting. Experimental graph and texture directories are excluded from release presets. Existing practice effects remain.
- Original Optical geometry keeps its source orientation/scale; opening/closing, scene timeline, original arena materials, complete effect rendering and audio remain open.
