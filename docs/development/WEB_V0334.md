# v0.3.34 — original weapon-animation milestone

This stage starts from accepted Web32, not the failed Web33 candidate. It adds source-model weapon poses, physical female anatomy correction, original static Optical geometry, and lifecycle cleanup. It retains the accepted practice attack presentation and combat rules.

## Released behavior

- Known M/F weapon action bindings only: 31525, 31526, 31530, 31533. Original sampled model-space PAP poses are synchronized to the simulation clock. Male windups are exercised before impact. The female zero-lead resolution fallback is **not** certification of a visible full female windup/attack sequence.
- Pause freezes sampled state; same-seed R releases ownership. No particle-mask adjustment is presented as a fidelity fix.
- Unverified source AVFX is disabled in release templates. Source/editor runs can explicitly use `--experimental-source-effects`; this requires the editor feature and is not a product setting. Experimental graph and texture directories are excluded from release presets. Existing practice effects remain.
- Original Optical geometry keeps its source orientation/scale; opening/closing, scene timeline, original arena materials, complete effect rendering and audio remain open.

## Evidence and publication gate

[Source/native receipt](../evidence/source-milestone-v0334.json) binds the changed files and actual four-combination Main runs. Exact combat-state and actor serialization agree with presentation disabled when the same time-step sequence is used. The first failing comparison used different step subdivisions; its raw differences and failed report remain private evidence, not a product failure silently relabelled.

The final source gates include 46 default-mode checks, 58 native-mode checks (12 actual screenshots), 51 experimental boundary checks, 13 experimental lifecycle checks and 292 physical-weapon/model checks. Source/native testing does not replace actual exported Web startup, pause, input, retry, public report and image checks. Publication requires those checks against the exact new PCK, HTTPS byte verification and recoverable activation.

Windows source rendering is not acceptance of a packaged native executable. This milestone is not all-phase/all-guide/original-game equivalence. Full source particles remain an open subsequent milestone, including masks, host color/alpha controls, billboard orientation and branch-matched reference timing. Web33 remains reserved for the preserved failed candidate.
