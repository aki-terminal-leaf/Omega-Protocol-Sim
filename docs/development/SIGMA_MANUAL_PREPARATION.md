# Sigma 莫古力手標協作候選

v0.3.15 來源候選已整合，新匯出的 Windows／Web 同一 PCK 十三組檢查及實際 Windows Chrome WebGL2 操作已通過；**原生 GUI 操作、發版與部署仍待完成**。固定站仍是 v0.3.13；v0.3.14 Omega 候選已有來源／匯出包／Web 操作證據，但原生操作驗收仍待桌面空檔。兩者都不表示全部攻略或完整 AVFX 已完成。

## 玩家操作與 NPC 責任

- CN Sigma 普通練習使用手動上標；玩家依真實 Dynamis、Near／Far World 與現有標記自行決定。NPC 只操作自己的標記，不替玩家移動、疾跑或上標。
- 非 World 的一層玩家可擔任打擊 1～4；其餘閒人使用止步。打擊 5 只替補唯一缺少的 1～4 工作，保留原始打擊 5，不新增第五個工作或取代完整的四個工作。
- World 不要求虛構按鍵。玩家錯標、漏標或對他人的明確標記都保留；NPC 不會把玩家或玩家已標記的目標改成隱藏答案。合法換號可以使 NPC 對自己的標記作出相應選擇。
- 未解工作不進入原本的完整分工導航，也不以 `-1` 索引到最後一名角色。真實 World、塔、手臂、雷射、層數與死亡仍由現有碰撞／狀態判定。
- 輔助模式只輔助分配標記，仍由玩家控制自己；示範與合成檢查點明確列為輔助，不能列為手動通過。

## 觀察、鎖定與紀錄

使用產品現有可見 World／Dynamis 的入口觀察，不因炮標出現而發明新的上標時限。第一次來源路徑分流前鎖定分工，是訓練器的實作邊界，不冒稱攻略規定或原遊戲精確時戳。止步 1／2 的空閒數字順序也明示為實作慣例。

鎖定保存真實所有者、事件序號、時間、原始標記與正規化工作。後來改標保留為現在的證據，但不能回寫鎖定分工。報告分開顯示：

- 分流前手標是否完成，以及玩家實際自標收據；
- 現在分工是否仍一致，以及晚改標事件；
- 真實戰鬥成敗；
- 手動／輔助、檢查點與來源精度。

B 內草稿不重標舊成績；套用先保存舊輪，再以相同點名重新開始。R／段落重試恢復各自的實際入口狀態；JSON 還原保留整數語義，不靠轉型重選人或修改層數。

## 來源與保留範圍

來源為 [CN 原圖第 10～11 區塊](../research/CN_POSTER_AUDIT.md)及原始 [公開一圖流](https://www.bilibili.com/opus/800287973844189204)。打擊 1／4 遠傳、2／3 引導手臂，World 站三圈；數字及路徑依既有相對 F 的實際資料，不是固定絕對方向。

不從入口六個一層／兩個零層外推完整伺服器亂數，也不增加未證的 World 必須一層限制。其餘四個社群不套用 CN 手標；保留既有攻略協作，未取得原文的手標責任仍待補證。初始往 F／背 F 的精確動畫時序、更多種子及所有合法分支，仍需逐來源核對；本候選不因此取得整套攻略認證。

## 驗收邊界

純規則、實際移動重播、真實 Main 輸入／重試／保存與 Windows／Web 操作分開驗收。重播驅動的玩家輸入不是原生真人完整操作；工程測試通過不是已部署或已通過原版逐幀對照。實際數量與最終來源釘選應在本候選完成整合及平台驗收後填入，不以尚未執行的測試作成績。

### 本次限定來源證據

純規則 52 項、18 個實際移動重播／1,534 項檢查及 Main 真實輸入／保存／重試 170 項通過。選定案例涵蓋八職責、打擊 1～4 合法選擇、唯一打擊 5 替補、漏／錯／晚標、輔助及正常生成的零層 World 族群；不是全部種子與分支的交叉矩陣。

必要共用回歸包括 Sigma 預處理 12,294 項、塔容量／重開 362 項、5,221 項及 640 組幾何、Omega Main 152 項、標記 UI 9 項、五攻略 Sigma 與 20 機制各第一打法。最後一項不是完整 100 選項或所有社群認證。候選已獨立覆核，原始失敗與 JSON 比較／選單測試器修正均保留；Web 已核對固定種子、真實自標、同入口輔助、塔、分流鎖定、晚改標及R清除，且已收回JSON與實際畫面；原生 GUI 仍待實際桌面空檔。此輪未獨立擷取實體GPU身分，不把WebGL2日誌當AMD硬體證明。
