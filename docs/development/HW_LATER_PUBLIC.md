# HW 後三輪：只依實際公開塔提示行動

後三輪 NPC 轉向、選塔與塔後交接，現在接到實際 Arena 已顯示的四塔。來源完成限定檢查；新 PCK／Windows／Web 待平台階段補齊，固定站仍 v0.3.34。

## 行為

- 揭示前依已知角色／位置中立準備，不讀尚未顯示的塔方向。
- 揭示後以公開四塔顏色／幾何建立本次／本輪觀察；後續路線用該觀察與角度無關的既有交接步驟。
- 玩家自行移動；同狀態搭檔依玩家真正獨占塔範圍回應選擇。及時返回更新責任，太晚返回保留真實失敗。
- 矛盾顯示封鎖該輪，不回退 pending 事件／攻略答案；已觀察後單純消失可保留記憶。
- 暫停不推進、重試只還原當時記憶，新開始清空。合成測試提示仍標 assisted，不能升格一般顯示來源。

不更動 RNG、玩家座標／按鍵、6m/s 移速、塔／攻擊範圍、狀態傳播／到期、死亡或成功條件。hw_runtime 只為公開塔加輪次／起點標籤。
