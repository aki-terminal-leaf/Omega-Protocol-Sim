# Cannons：由實際顯示炮標決定動態分工

v0.3.17 來源限定增量已驗收，尚未匯出或平台測試；固定站仍為 v0.3.13。以下是分層工程證據；不是手動完整通關、全部攻略或完整 AVFX 認證。

## 公開資訊與玩家責任

- 炮頭標圖像與兩輪三人顯示原已存在；本次補的是觀察／發布契約，不是新增原先缺少的頭標。
- 動態排序只使用 Arena 當前真正建立、可見且有貼圖的炮標 Sprite3D 所發布的完整三人組；不能讀隱藏的未來事件、預算終點或未公開持有人。
- 實際收到第一輪完整三人後，可依公開的六名非坦、兩輪互補規則推知第二組；這不冒充第二輪已顯示。沒有第一組記憶時，實際第二輪完整三人亦可建立本輪觀察。
- 只有依當輪點名變動的排序需要等待觀察。固定職責分散、公開恢復站位與坦克誘導位置是合法公開規則，可預先採用；不把所有提前站位都判成偷看。
- 玩家須自行移動與保持坦克最遠誘導；NPC 不接管、瞬移或加速救回錯走的玩家。中立出生為訓練配置，不宣稱原遊戲拉怪陣形。

## 不改判定與可用選項

UI 保留七個攻略選項與既有靜態／動態／分坦差異。移速仍為 6 碼／秒，五次坦克 cleave 在 6／8.1／10.1／12.2／14.3 秒各按當時真實最遠兩人選取；兩次 protean 在 6／15 秒，流程終點 15.1 秒。原判定、碰撞與期限不放寬；目前扇形仍為 120°。KR 來源 90°／120° 衝突未解，不按本次測試反推原遊戲幾何。

## 實際觀察與明示分段輔助分帳

普通新開局、已觀察檢查點還原與合成分段輔助是三件事。後者明示 `分段輔助`、`不計完整練習`：只在略過的過去流程使用 builder 第一波持有人，儲於獨立 `assisted_checkpoint_fixture_not_observed`／`builder_first_wave_targets` 欄位。它不是第一輪實際觀察收據；不填入 `first_ids`／實際觀察時間，不將隱藏未來第二波當已顯示，也不取得完整練習信用。真正顯示後的頭標發布才填實際觀察欄位；不抹除真實 live-run 傷害或失敗。

JSON integral float actor ID 的修復僅讓呈現端正確比對人物與死亡／炮標；不重寫 pending、history、target、dead 等權威陣列來製造觀察或判定答案。

空收據保留先前有效觀察。任一非空但不完整、矛盾或非法收據會永久封鎖該 epoch 的動態分配，直到新開局；即使先前已有完整知識或稍後恢復完整三人也不解封。這是保守的有限實作政策，**不是攻略要求**；缺貼圖／部分可見後恢復的合法情境仍是恢復能力缺口。靜態／坦克／公開恢復位置不因此變成隱藏情報。
