# 場地標記與目標標記規劃

狀態：**v0.3.3 基礎功能已發佈；本次開發分支補上配置庫、拖放／旋轉及自訂鍵位，尚未發佈新版**。

已接上17種手動標記、自己／隊友操作、唯一轉移／清除、下一空號、
原版八標字形與配色、通用／外圈／空配置與JSON座標編輯、設定保存、
重開／重練快照及JSON報告。B開面板、M自標、N下一空號、Backspace清自標、
Ctrl+1–8直接對自己上攻擊編號；不替換Boss/LB目標，也不打斷LB讀條。

本次已完成[多組配置庫、可視拖放／旋轉及可自訂按鍵](MARKER_EDITOR.md)。
下面保留完整規劃。**逐攻略來源預設、完整手動／輔助／不使用模式與依實際
標記反應的Bot規則仍未宣稱完成。**
頭頂手動標記目前使用原版UI素材的獨立顯示，並非已找到其原版頭頂AVFX。
本次使用者已允許桌面操作；實際採用的驗收方式仍逐次據實記錄。

## 1. 現況與既有方案檢查

- TOP 已有固定八標：A、1、B、2、C、3、D、4，從北方起每 45 度一個，
  半徑 13；目前是地面文字與圓環，不是可選擇／編輯的標記配置。
  來源：[arena.gd](../../top/scripts/arena.gd) 的 `_ready()`。
- TOP 尚未接入玩家可操作的目標標記；機制點名圖示、Buff／Debuff、
  圖形解法設定不是這項功能，必須保持分離。
- 已檢查本倉庫 DSR 原作，無須另找插件或自建完整聊天系統：
  [waymark_controller.gd](../../scenes/controllers/waymark_controller.gd)
  依設定載入 APD／LPDU 兩組場地標記；
  [target_marker_controller.gd](../../scenes/controllers/target_marker_controller.gd)
  提供攻擊 1–4、止步 1–2、鎖鏈 1–2、四種圖形，共十二種資源。
- DSR P6 的 AM／MANUAL／NONE 是攻略配置；`seq_wroth.gd` 的 MANUAL
  仍由時間軸呼叫 `assign_am()`。不能把這個名稱當成已驗證的
  「玩家按快捷鍵對自己上標」功能。
- 優先沿用已存在的互動概念及確認可用的資源。TOP 與 DSR 的專案根目錄、
  角色型別和授權邊界不同；不直接搬用依賴 PlayableCharacter／Autoload
  的 GPL 控制器至 MIT 模組。沿用素材前核對來源、授權與匯出可用性；
  不因原作有十二種，就宣稱已具備現行遊戲全部標記。

## 2. 使用流程與功能範圍

### A. 場地標記：攻略預設＋獨立自訂

1. 維持「選機制 → 選攻略 → 開始」；設定內新增「場地標記」。
2. 選項包含「跟隨攻略建議／已存配置／自訂／不顯示」。攻略建議須逐機制
   核對來源，不把 Elemental、LPDU 或某語言當成全機制共用的唯一配置。
   未核對時明示使用目前通用八標，不冒稱攻略原版。
3. 支援 A–D、1–4 各自開關、場內位置與整組旋轉；以場地絕對北方為基準，
   不跟隨鏡頭或 Boss 轉動。編輯可拖放或輸入座標，提供名稱、儲存、複製、
   還原及 JSON 匯入／匯出；匯入僅接受版本化資料，拒絕重複 ID、非有限值
   與越界位置，無效匯入不得覆蓋原配置。
4. 預覽與編輯只在開始前／Esc 暫停設定中進行；練習中不允許即時搬標。
   已開始的練習若改配置，需重新開始並留下原次紀錄，不靜默改寫成績。
5. 換標只改標記，不旋轉機制、Boss、角色路線或判定區域。
   自訂標位與攻略不相容時不自動改答案；只有確實以標記定義分工的攻略，
   才透過明確的攻略規則引用該標位。

### B. 目標標記：可對自己或隊友操作

- 支援攻擊 1–8、鎖鏈 1–3、止步 1–2 及 ○／＋／□／△，共 17 種。
  原版 Marker 表及 UI 素材已核對；Plus 不與機制強制的 × 點名混用。
  角色頭頂獨立特效仍待查證，不以 UI 圖示取得冒稱特效已完整還原。
- 初期可點隊友清單選人，再開小型標記面板；提供獨立的「對自己」操作，
  不必先選中自己，也不改變目前 Boss／LB 目標。3D 點人可後續擴充。
- 標記同時顯示在角色頭上與隊友清單獨立欄位，與 Debuff 並存；
  不擠掉 Debuff、不遮住機制強制點名圖示，不以顏色作唯一辨識。
- 一人最多一個玩家目標標記，一個標記同時只屬於一人；同標換人會轉移，
  換標會移除舊標。重複同一動作採冪等，清除另有明確操作。
  上線前以官方說明／可驗證實機行為核對一致性，不僅參考 DSR 控制器。

### C. 自我標記：第一批核心功能

- 可設定一鍵「對自己上指定標記」、「對自己上下一個可用攻擊編號」、
  「清除自己的標記」。無需開面板、不暫停、不自動站位，也不改選取目標。
- 在練習設定選擇標記與自訂快捷鍵；可選擇顯示小型快捷列，預設不常駐
  大面板。不搶用移動、1／2／3、F、V、P、R、Tab、Esc 等既有功能；
  衝突明示，文字輸入與設定視窗中不得誤觸，按住不連發。
- 下一個可用編號以當下已使用集合決定，不從隱藏解答指定；已滿時明確
  失敗、不搶標。需要固定編號的攻略仍用指定標記操作。
- 預留巨集風格動作，例如 `/mk attack1 <me>`、`/mk bind1 <me>`、
  `/mk off <me>`；初期可直接用按鈕／快捷鍵完成同等動作，
  不把完整聊天框、巨集語言、連續自動判讀巨集列為首版依賴。

### D. 攻略整合與訓練模式

- **手動練習（一般練習預設）**：玩家自己判讀、自己標；隊友僅依該攻略
  已核對的公開訊號與時間點上標，不替玩家補標或更正錯標。
- **輔助上標**：模擬團隊自動分配，供熟悉跑位；明確記錄為輔助模式，
  不能混記為手動上標通過。
- **不使用玩家標記**：關閉這一層，不得連帶關閉機制強制點名／Debuff。
  場地標記開關與上述模式彼此獨立。
- 支援自我標記的攻略逐條記錄「根據哪個可見訊號、何時可判讀、用什麼標、
  何時清除、標記如何影響分工」。先檢查 P5 Sigma／Omega 等候選，
  不能未查證就宣稱所有打法都需要、或全部已相容。
- 標記本身不代替戰鬥判定。漏標、錯標、晚標是獨立的協作檢討；
  AoE／連線／站位仍按真實互動判定。只有攻略確實依標記分工時，
  隊友才依當時實際標記反應，不能一邊顯示錯標一邊偷偷按正解移動。
- 正常練習不提前顯示應標答案；機制真正點名才正常顯示。
  正確標記提示限示範／輔助或失敗檢討，維持既有遊戲畫面優先設計。

## 3. 資料、狀態與程式接點

- 新增獨立標記狀態模組，例如 `top/scripts/markers.gd`；不要混入
  `party_statuses` 的 Buff／Debuff 集合或 LB 選取狀態。
- 場地配置包含 schema 版本、配置 ID／名稱、來源、八標的啟用狀態與
  場地 X/Z 座標；攻略只引用建議配置及上標規則，允許使用者覆寫。
  `mechanic_strategies.json` 的方法項目可引用 `marking_profile`，
  未指定者回退目前通用八標。
- 目標標記保存雙向唯一映射、事件序號，以及 `{sim_time, actor, target,
  marker, operation, source}`。同時刻動作按事件序號處理，避免幀率改變結果。
  `source` 區分 player／bot／assist／checkpoint；模式與設定獨立持久化。
- `arena.gd` 改為讀取場地配置並繪製獨立目標標記；`main.gd` 負責設定、
  快捷鍵與隊友清單選取，保持滑鼠鎖定／拖曳鏡頭與 UI 點擊的界線。
- 場地配置可跨練習保存；目標標記屬單次練習狀態。重新開始清空目標標記；
  重練段落還原該段入口快照，不一律清空，也不帶入失敗後的殘留標記。
- 檢查點由已發生的可見事件還原，不能注入未來的正確分配。
  暫停設定與失敗檢討不能偷偷接受上標動作改寫通過紀錄。
- JSON 報告新增實際場地配置快照、標記模式、上標事件及段落標記快照；
  保留 seed、攻略與輸入，使漏標、標記轉移、晚標及重試可重現。
  報告 schema 若升版，同步記錄相容方式。
- 死亡／復活、同時操作、上標可作用目標及現行標記全集等遊戲細節，
  在行為驗收前核對；未核對的語義不得標榜完全比照遊戲。

## 4. 實作順序與驗收門檻

每個增量保持有界、獨立審查及可交付；不因整體規劃一次重建全部機制。

1. **場地配置**：抽離現有八標 → 通用配置／不顯示／攻略配置選擇 →
   自訂座標、旋轉、儲存與 JSON。先保留 v0.3.2 的預設位置作回歸基準。
2. **目標標記與一鍵自標一起交付**：唯一映射與轉移／清除 → 頭頂與隊伍
   同步 → 面板及快捷鍵。不能只做外觀就宣稱已支援自己手動上標。
3. **攻略規則**：先完整驗證一個確有自標需求的打法，再擴展其他打法；
   加入手動／輔助／無標模式、隊友依標反應與協作檢討。
4. **整體交付**：重試與檢查點、存讀檔及報告閉環；Windows／Web 匯出後
   headless 操作與畫面驗收通過才發布新版，不改寫舊版。

必要驗收案例：

- 換配置／旋轉鏡頭後地面標位仍對；非法匯入不破壞原設定；
  新增標記前後相同 seed 的戰鬥幾何和判定不被純顯示設定改變。
- 移動中對自己上標，不中斷移動／LB、不換選取目標；同標轉移、換標、
  清除、下一空號及編號用盡均有明確結果；文字輸入不觸發快捷鍵。
- 八人同時有 Debuff 與目標標記時，頭頂及隊伍清單正確且清楚；
  近／遠鏡頭、俯視與 Web 縮放仍可辨識，Tab 不會隱藏必要標記。
- 實際快點、拖曳、開面板再關閉，不留下滑鼠鎖定，不吞掉 JSON 按鈕點擊。
- 漏標／錯標／晚標不被偷偷修好；手動與輔助報告可區分；
  重開／重試／檢查點沒有殘留或未來答案。
- 依本次使用者授權驗證；保留程式回歸及實際匯出Canvas證據，不沿用舊版驗收。
