# TOP v0.3.30 — Hello World later-round choice fix (Web-first preview)

Play: https://top.servicing.cc

## Fixed

Hello World NPC tower allocation now follows an eligible player's reversible choice before later-round tower judgment, instead of retaining an earlier visit to the alternate tower. Allocation freezes after judgment. This fixes the controlled Elemental early-return case; genuinely late returns still fail through modeled attack/tower outcomes. Player verdict is not an exact-coordinate requirement.

Noncentral legal in-tower poses, every guide/role/round and the later public-receipt gap are not fully verified. First-wave browser regression is not later-round manual browser proof. SwiftShader is not physical GPU/FPS certification. Full20/102 correctness, measured optimization, and complete AVFX remain active.

The separately pushed P2 CN D2/D4 sorting correction is not included in this pinned build.
