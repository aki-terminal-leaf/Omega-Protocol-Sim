# HUD CPU 開銷優化（2026-10-23）

此項依使用者要求排在全機制NPC／攻略核對後。量測是**同一個實際Main場景的HUD方法CPU時間**，不是GPU、整幀或使用者裝置FPS。

## 變更

- 每次update_hud只建立一次八人狀態觀察，供可見HUD共用。
- 全螢幕練習期間，不再重新排版被隱藏的設定頁RichText隊伍表。
- 開啟設定頁時立即刷新該表；既有直接sync呼叫仍即時讀取狀態。
- 不跨幀快取狀態、不降狀態更新頻率、不隱藏角色或提示、不改模擬步進、移速或判定。

## 驗證與限制

獨立靜態審查PASS；八人狀態222項、畫面／設定／LB控制27項、真實成功與失敗結果10項，合計259項檢查通過。原NPC審查階段的20機制／60移動課程／522快照是修改HUD之前的相鄰checkpoint，不冒稱此次重新跑完。

實際低幀數是否恢復仍需使用者發生問題的平台／場景復驗；不能把本表15%～49%的局部CPU改善寫成FPS提高15%～49%。尚未做GPU材質／原版模型LOD改動，也沒有犧牲攻略提示。開發分支的推送不等於固定測試站或Windows包已更新。
