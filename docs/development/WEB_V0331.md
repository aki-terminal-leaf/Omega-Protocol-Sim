# TOP v0.3.31 — P2 CN / 莫古力優先序修正（Web-first preview）

固定預覽：https://top.servicing.cc

- 修正 P2 CN 圖案配對的優先序：同圖案高順位面向眼睛站左、低順位站右；D2/D4 同圖案時 D2 左、D4 右。初始八人隊列與玩家準備位置保留實際移動，不以攻略目標座標單獨判定玩家失敗。
- 本版有 21 組同一匯出 PCK 驗證。CN priority：1024 checks / 640 courses / 512 pairs；lineup：64 checks；實際 Main 全 NPC demo：38 checks / seeds 2、6。
- 新鮮匯出瀏覽器驗證：20 項檢查、118 份公開報告、8 次實際像素 ACK、18 張實際審查圖片。包含普通練習的人類 WASD 入列、放開按鍵不被 NPC 接管、八人順序與 R 同種子重練。Seeds 2/6 的圖案與 Fire 配對站位是 NPC demo，停於 Fire 判定前，不是玩家通關證明。
- 圖案由實際 PNG/HUD 獨立辨讀；眼睛方向使用 source cue oracle，並非公開報告直接量測。
- 所附 Web ZIP 可離線使用：需已安裝 Python 3，Windows 執行 start-web.cmd；macOS/Linux 執行 python3 start-server.py，再開啟 http://127.0.0.1:8765/。包含原始碼 ZIP 與雜湊／驗證摘要。

限制：這是 headless SwiftShader Web-first preview，不是 Windows 原生執行檔或原生／實體 GPU／FPS 效能認證。原生驗收仍待實際證據；全 20 機制與 102 攻略分支的完整正確性、量測優化、完整 AVFX 仍持續進行。既有失敗保留，不冒充通過。
