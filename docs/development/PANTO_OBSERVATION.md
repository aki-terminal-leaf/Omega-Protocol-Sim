# Pantokrator：從已顯示情報決定 NPC 行動

v0.3.16 來源限定驗收、同一匯出 PCK 的 17 組檢查及實際 Windows Chrome／AMD WebGL2 輸入／畫面驗收已通過；原生 GUI 為 UNRUN，待實際桌面空檔，尚未部署。固定網址仍是 v0.3.13；v0.3.14／v0.3.15 候選的來源、實際匯出包及 Web 操作已有限定證據，但原生 GUI 仍待實際桌面空檔。這不是全部攻略、最佳化或完整 AVFX 完成聲明。

## 玩家與 NPC 的情報邊界

- 開場使用固定、公開且與本次亂數答案無關的中立站位，不直接出生在首輪飛彈的解答點。
- 公開的個人 Inline 數字、隊伍職責與所選攻略決定分組；來源消失後保留已觀察的數字，不重讀未來分工。
- 畫面真正顯示第一組對向火焰後，NPC 才能讀取軸向；此時仍不知道順逆時針，不預先依方向跑位。
- 旋轉方向只來自已顯示的連續兩組錐形預兆。缺過一組時重新建立觀察參考，不能把較晚的模180角度誤認成反向。
- Main 的同一畫面可能包含多個模擬步進。只有目前 Arena 實際建立的可見預兆網格發布後，觀察才交給下一次 Main 更新使用；內部步進不提前取得尚未發布的提示。
- 缺少／矛盾的公開數字或未支援的選項資料不回退讀取隱藏答案。玩家仍自行移動；NPC 不把玩家瞬移、加速或救回正確位置。

## 保持不變

既有移速6、0.1秒路徑取樣、火焰／水圈／飛彈／分攤時間與幾何、碰撞、角色選人及傷害判定均保留。畫面在目前錐形預兆集合變更時立即更新；一般0.07秒重繪節流不因此全面停用。這是資訊正確性修正，不是效能改善成績。

相同種子重來清除本次觀察；段落重練恢復該段已知狀態；JSON 只保存已觀察內容，不從 pending事件或隱藏路徑重建漏看的方向。合成檢查點仍明確為輔助，不算完整手動練習。

## 來源精度與未完成範圍

目前模擬器的名義軸向／方向顯示落在T2.1／T7.6，這是現有提示政策的結果，**不是原遊戲 AVFX 提示出現時間已獲證實**。原遊戲第一／第二可讀提示的共同T0與首次傷害對照仍為 `source_unknown`；不以傷害時間減四秒當取證。五社群的既有相對安全區／數字分隊與CN雙路線沿用 [P1來源核對](../research/P1_FIDELITY.md)，不外推所有人類路徑、全部種子或原始亂數權重。

本候選只修Panto；[Cannons v0.3.17 候選](CANNONS_OBSERVATION.md)另列且限定來源驗收通過、平台另驗，P3轉場仍待處理。20機制／100選項矩陣全部維持 `not_certified`，不以本項Bot全過認證整套攻略。

## 分層驗收

有限可行性實驗先驗72種朝向／方向／攻略路線，與正式程式分開；原型未合入產品。正式驗收必須使用真實 `Interactions.bot_goal`、實際移動／事件／判定、逐幀資訊隔離、漏看提示負向對照、JSON、Main八個玩家職責與畫面幾何，以及必要共用回歸。

來源驗收與Windows／Web實際輸入、OS畫面及固定HTTPS部署另計；未執行者不填成通過。最終數量由凍結來源與實際檢查紀錄填入。
