# Original-resource integration: source stage, GPU acceptance pending

2026-10-27. This candidate is based on accepted Web32 (`483141a`), not the frozen, failed Web33 NPC candidate. It does not resume unrelated NPC correctness work. **The live site has not been updated by this source stage.**

## Implemented

- Import a hash-verified local Lumina bundle with `tools/import_source_effects.py`; compile original AVFX graph/geometry/curves and source TMB bindings. No original media is committed to Git.
- M/F original sampled PAP animations use model-space global bone overrides, not incorrectly interpreted parent-local TRS. The resident animation is restored when the visual action ends.
- A four-layer TC1–TC4 material subset, source UV transforms/wraps, source geometry and bounded planar decals augment the existing graph player.
- Practice presentation uses the simulation clock and actual resolution receipts. Pause/retry/mechanic changes do not retain old effect instances. Known weapon wind-ups share their source local clock with effects; other effects currently use the actual resolution as their local time origin.
- Original Optical Unit geometry/materials replace the procedural object when installed. The source anchor/pitch/scale are preserved in the scene placement. The lid remains at its source default pose: **native scene timeline/opening/closing is not implemented**.
- Omega-F neutral anatomy keeps ordinary legs. Only the physical staff mesh, not ordinary legs, supplies the STAFF observation; this avoids a premature NPC weapon cue.
- A positive source `ClCn` child limit now constrains direct children in stable birth order. Particle occupancy uses declared life/StartFrame; emitter occupancy uses the supported generation-stop policy. Native recycling, effector kills and descendant-tail occupancy remain unknown.

## Extracted versus playable

The merged private pack contains **166 AVFX graphs, 787 decoded textures and 128 TMBs**, indexed against 168 observed ability IDs. All 227 direct dependencies in the preceding six-phase analysis were acquired. Those totals are extraction/parse counts, **not 166 fully reproduced effects or 96 completed presentation units**.

Unsupported emitter/particle types, texture masks/special operators, screen blend, UV distortion, soft particles and other original-engine features remain explicit diagnostics. Effects have a bounded six-second preview lifetime. Full scene/cinematic/audio reconstruction and complete phase/branch fidelity are not claimed.

- 292 physical-weapon/anatomy checks and four actual PT demo courses.

The first provisional Web probe did not enter its intended demo and had unacceptable gray/dark material presentation. Canonical GLB import settings were restored. A second VPS browser attempt was terminated by an actual kernel OOM; it is **not a Web PASS**. Failed evidence is preserved. Actual browser shader/texture/pixel comparison is the next gate.
