# Party Synergy：公開身體幾何辨認新北

## v0.3.25 已發布 Web-first；原生另待驗

本增量只修正 Elemental、Aether、LPDU 既有公開分組語義下的新北觀察。NPC 不再讀取私有 north 或已解答站位；在真正可見的男／女分身身體更新後，從五個外圈男分身的世界 XZ 幾何辨認唯一方向。中心女分身可缺席，而且不提供方向；單獨武器、標籤、空節點、隱藏身體都不算已看見。沒有可靠來源時維持 NPC 當前位置，玩家仍只受自己的輸入控制。原有擊退前置集合不變。

當前模擬器幾何為半徑13、相對方向0／±45／±135度；半徑、角度與重複點容差是實作容差，不是原遊戲認證。原始攻略的完整五點座標、原遊戲確切出現幀仍 SOURCE_UNKNOWN；LPDU 武器分組側軸另行保留未知，不因此推導。

有效觀察是真正已知的過去：之後真正消失或部分消失可保留；完整矛盾、重複、畸形或錯誤幾何會撤銷並封鎖本輪，不能讀私有答案修復。當前來源在第一次形成前缺失，就等到合法可見來源。每輪／選項／時間／準備起點／basis 與 JSON 還原均驗證。實際畫面、未呈現 headless 與明示分段輔助使用不同 basis；粗時間子步不假造已看見的提示。R 整輪重開清除觀察和合成過去；同段重練只恢復快照當時已知資料。晚段 checkpoint 明示「分段輔助」，不冒充實際觀察。
