# 起始預兆與最後 0.5 秒傷害提示

2026-10-22／v0.3.10。這是顯示分類修正，不變更傷害事件、尺寸、玩家移速或亂數生成條件。

- **機制預兆**：必須先看到才能判讀的來源，依各自時窗呈現；不是等到傷害判定才出現。起始地面預兆用琥珀色，最後 0.5 秒的傷害提示沿用紅色。
- **一般傷害範圍／後續推進**：仍只在實際判定前 0.5 秒顯示。不能把未出現的後續地火、旋轉火焰、雷射或安全區提前公開。
